# Argos English → Czech 1.9.6

This archive is the original Argos EN–CS model download. The Windows builder verifies its SHA-256 and stages only the model weights and tokenizer files. Build runners do not need to contact the Argos CDN.

The original OPUS-MT model by Jörg Tiedemann and Santhosh Thottingal is licensed CC BY 4.0. The archive contains the upstream attribution. See the citation in its README.
